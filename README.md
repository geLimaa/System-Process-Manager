# System Process Manager

A Python-based system process manager for monitoring and managing system processes and resources.

The project uses `psutil` to interact with the operating system and provides real-time information about CPU, memory, disk usage, and running processes.

## Features

- Real-time CPU, RAM, and disk monitoring
- Process listing with PID, name, user, CPU and memory usage
- Process sorting by resource consumption
- Process information/details
- Process filtering
- Process termination
- Process suspension and resumption
- Interactive terminal interface

## Technologies

- Python
- psutil
- Linux
